# NexaScripts File Organizer

![File Organizer Screenshot](screenshot.png)

A desktop application built with Python to organize files automatically by category.

## Features

- Automatic file organization by extension.
- Modern graphical interface using CustomTkinter.
- File preview before organization.
- Duplicate file detection.
- Operation history saved in CSV format.
- Error handling and confirmation before moving files.

## Technologies

- Python
- CustomTkinter
- CSV
- Tkinter
- pathlib
- shutil

## Installation

1. Install Python.
2. Clone or download this repository.
3. Install the required dependency:

```bash
python -m pip install customtkinter
```

4. Run the application:

```bash
python organizer.py
```
